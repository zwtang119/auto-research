# 300-Agent 2026 世界杯夺冠预测 - 执行计划

## 阶段 1: 数据研究（Real Data Gathering）
**目标**: 联网检索 2026 世界杯真实数据，为 300 个 Agent 提供统一的事实基础
- FIFA 世界排名（最新）
- 各队阵容身价（Transfermarkt）
- 博彩夺冠赔率（主流博彩公司）
- 关键球员伤病情况
- 小组赛程与对阵
- 东道主信息（美国/加拿大/墨西哥）
- 历史世界杯夺冠记录

**输出**: `/mnt/agents/output/wc2026_data.md` — 所有真实数据的汇总文档

## 阶段 2: 300 Agent 预测（Parallel Prediction Swarm）
**目标**: 创建并分派 300 个独立 subagent，每个都有独特人设

### 10 个派别 × 30 个 Agent = 300 个
1. **数据派** (30人) - 看身价、Elo、xG、近期战绩
2. **赔率派** (30人) - 跟随博彩盘口与隐含概率
3. **老球迷派** (30人) - 重历史底蕴、大赛基因
4. **玄学派** (30人) - 东道主魔咒、卫冕魔咒等
5. **主帅视角派** (30人) - 看战术体系、克制关系
6. **伤病赛程派** (30人) - 重伤病、赛程、气候
7. **黑马派** (30人) - 专挑被低估的冷门队
8. **阵容年龄派** (30人) - 看核心年龄结构
9. **心理抗压派** (30人) - 看大心脏、点球、逆境
10. **建模派** (30人) - 蒙特卡洛/泊松等量化模拟

### 每个派别内 30 个 Agent 的具体身份差异化
- 不同国籍背景（巴西老球迷、德国老球迷、阿根廷老球迷...）
- 不同联赛背景（英超粉、西甲粉、意甲粉...）
- 不同职业身份（退役球员、体育记者、数据分析师...）
- 不同偏好倾向（保守型、激进型、中立型...）

### 每个 Agent 输出格式
```json
{
  "agent_id": "唯一编号",
  "faction": "所属派别",
  "persona": "具体人设",
  "champion": "冠军队名",
  "top3": ["第一名", "第二名", "第三名"],
  "confidence": 0-100,
  "reason": "一句话理由(必须用真实数据支撑)",
  "faction_detail": "所属派别细分身份"
}
```

**分派策略**: 创建 10 个 faction agent 模板，每个模板内包含 30 个具体人设。由于不能分批，将同时分派所有 agent。

**输出**: `/mnt/agents/output/predictions.json` — 300 条结构化预测记录

## 阶段 3: 聚合分析（Aggregation）
**目标**: 对 300 个预测结果进行多维度聚合

### 聚合算法
1. **夺冠概率 = 各 agent 冠军票按信心加权求和 → 归一化为百分比，取 Top8**
   - 公式: P(team) = Σ(confidence_i for agent_i picking team) / Σ(all confidence scores)
   
2. **分歧视图**: 每支队在每个派别内的得票分布
   - 10 派别 × N 支队的矩阵

3. **最大热门**: 概率最高的队
4. **最被低估的黑马**: 
   - 黑马派支持率 - 赔率派支持率 落差最大的队
   - 或派别间分歧最大（标准差最高）的队

**输出**: `/mnt/agents/output/aggregation.json` — 聚合结果

## 阶段 4: 可交互网页构建（Web App）
**目标**: 构建三区交互网页

### 视觉规范
- 底色: #FBF9F1（暖白/米色纸感）
- 文字: #13233A（深藏青墨）
- 强调色: #9B2D20（砖红）或 #C8A45C（冠军金）
- 字体: 无衬线标题 + 等宽数据
- 交互: 平滑滚动、count-up、条形入场、hover 效果

### 三区结构
1. **过程区**: 300 个 agent 头像网格，随完成逐个亮起 + 派别代表性判断滚动
2. **结果区**: Top8 概率热力榜（概率条入场生长 + count-up）+ 最大热门 & 最被低估黑马点评
3. **分歧视图**: 可按派别切换查看分布

### 交互钩子
- 用户先押一个心目中的冠军
- 揭晓 300 agent 投票分布
- 高亮反馈: 用户选择与哪个派别一致 / 比主流保守还是大胆 / 多少 agent 同选

**输出**: `/mnt/agents/output/wc2026_predict/index.html` + 静态资源
