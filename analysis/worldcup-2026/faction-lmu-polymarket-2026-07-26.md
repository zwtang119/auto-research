## 3. Polymarket 定价机制（任务 4，回答用户四问）

### 3.1 价格是市场水位定的，还是人为划的？

**纯市场水位，零人为定价**。机制 = 链上中央限价订单簿（CLOB）：YES/NO 份额各 $0–$1、恒满足 1 YES + 1 NO = $1；价格从挂单互动中涌现——新市场最初无价格，首对匹配订单（买 YES 价 + 买 NO 价 = $1）铸造份额并定出开盘价；此后显示价 = 买卖价差 ≤$0.10 时取**价差中点**，价差 >$0.10 时取**最近成交价**。统一订单簿把"买 YES@0.60"与"卖 NO@0.40"镜像为同一单，等效双倍深度。结算走 UMA 乐观预言机（可争议挑战），不押平台信用。[注：rocknblock 2025-06 机制文；chainup 2026-05；laikalabs 2026-02 费率文]

### 3.2 "市场概率的声音"是怎么来的？科学吗？

声音 = **边际交易者用真金白银挂单形成的价格**，不是投票、不是民调、不是平台观点。三点结构性事实（2026）：月成交 >$200 亿（2025 约 $12 亿→2026 >$200 亿）；**约 3% 的交易者贡献了大部分准确的价格发现**（成熟玩家主导）；平台用 Maker Rebates + 流动性奖励池（2026-04 起 >$500 万/月，大赛月峰值 $800 万）购买深度。科学性评价（分层）：① 聚合机制有文献支撑（Wolfers & Zitzewitz 2004：价格≈信念的加权聚合）；② 但**价格 = 边际价格 ≠ 群体均值**——深钱包的意见权重天然更大；③ 已知偏差：favorite-longshot bias、对显著性事件的 recency 过调（佛得角 −7pp 即实例）；④ 单队 outright 相对比赛事级市场浅，"价格"与"概率"之间隔着一个流动性修正项。**结论：价格是有偏但可用的信念读数——可以当基线，不能当神谕。**

### 3.3 流动性核验（对 C11 的稳健性）

直接证据：佛得角之夜单名交易者输 $99 万、另一名赢 $470 万（Bloomberg/网易/搜狐）——单笔七位数盈亏证明冠军 outright 市场有实质深度，不是幽灵盘；平台级数据：2026 月成交 >$200 亿，体育专项流动性奖励峰值 $800 万/月。**残余诚实声明**：赛后历史订单簿深度/价差已无公开渠道逐日回溯（gamma API 对已结算市场不返历史档），C11 引用维持"按收盘价读数、未做逐日流动性调整"——但深度量级（七位数单笔）足以排除"薄市场噪声定价"这一反驳的主要形态。

### 3.4 可以套利吗？

理论上三个通道，现实中都有摩擦：
1. **多结果负风险**：同一事件全部 YES 价之和 ≠ $1 时，>1 全卖 / <1 全买锁利——但撮合引擎 + 套利者使偏差极窄（% 级以下），扣 taker 费（0.0625×p×(1−p) 抛物线，50 美分段峰值 1.56%）与滑点后所剩无几；
2. **跨市场套利**（Polymarket vs 体育博彩/其他交易所）：存在但受限于出入金成本、结算规则差异（90 分钟 vs 含加时）、时滞；
3. **信息套利**（如拿着"冻结信号"在 7-01 买 10% 的西班牙）：这正是"市场法国时代"的读法——事后看是机会，事前看是信念。我们不输出投注建议；对论文的意义仅在于：**错价幅度为"市场并非时刻有效"提供了量级证据**（冠军队五周低于赛前价交易）。
