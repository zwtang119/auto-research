## 总评

## A. v1.5 大改后的内部一致性 —— 部分通过

主干同步良好：执行摘要（RM:19-22）、§2 时间行（RM:45）、§4.6 B1 行"回放+前瞻蓄题双轨"（RM:166）、§7 首行（RM:226）、§8 检查点（RM:247）均已改口径，未发现仍默认 Stage 1 前瞻的显性段落。残留如下：

- **A-1（部分）B0.5 判据是前瞻思维残留**。RM:165 的"结算时延中位数 ≤72h"对回放臂无意义（历史事件即时结算）；"实测 x 分布覆盖分箱规则的最小比例"对回放臂是**可设计属性**（任务池固定、可先验枚举），不是只能事后实测的采样属性；且 pilot 是否演习回放管道（断网、快照加载、时戳校验）全文未声明（→E5）。

- **A-3（未通过，小）引证方向反转**。RM:120："参照范式显示 single-agent 基线**过弱**时加 agent 呈负收益"——解剖报告原文相反："negative returns once single-agent baselines **exceed** ~45%"（解剖:127；§7.1 同向）。且 RM:105 的表述（"single-agent 超 ~45% 后加 agent 呈负收益"）才是对的——**同文件两节自相矛盾**。能力地板结论可靠 floor-effect 论证另行成立，但现有引证把机制写反了，审稿人一查即穿。
- **A-4（部分）"Stage 2 预注册"措辞歧义**。RM:157 策略推导规则"随 Stage 2 预注册冻结"，而 RM:22 与 RM:246 均为"B1 前完成 OSF 预注册（含冻结粒度清单含 V̂(x) 与策略推导规则）"。若"Stage 2 预注册"被读成 Stage 1 之后的第二次注册，RT-8 的 fork-path 防护（"看完 Stage 1 结果后不得再改"）在流程上失效。需统一为"B1 前 OSF 一次性冻结"。
- **A-5（部分）§4.5 隔离条款部分赘余、前瞻开发段无角色**。RM:155"留出任务结算结果禁止进入 Stage 1 的 V̂(x) 分箱"在回放化后自动成立（Stage 1 本就不碰前瞻数据）；而 RM:153 的前瞻开发任务流在 v1.5 下只剩"自由调试"，未重新指派用途——它恰是 E4 可迁移性对照的天然载体，路线图没有接上。
- **A-6（通过）**§4.8 结算延迟监控（RM:187）对 B1 前瞻子流仍适用；§4.7 调用量公式（RM:172）对回放语义自洽（"已结算预测数"= 回放的已结算历史事件）。

## D. B0.5 pilot go/no-go 判据 —— 4 条可测、4 条部分、2 条带时序矛盾

管线层（RM:165）：
- D-1 trace 完整率 100%：可测 ✓。
- D-2 解析成功率 ≥98%：可测 ✓（双层判定窗口 RM:186）。
- D-3 结算时延中位数 ≤72h：可测，但**仅适用前瞻子流**；回放即时结算，判据适用范围未声明 → 部分。
- D-4 成本实测 vs §4.7 偏差 ≤50%（按子账）：**基准是区间不是点估计**（RM:173-176 给 10⁴–10⁵/10⁴–10⁶ 区间），无法判 50% 偏差；须 B0 一页成本模型产出点估计后才可执行 → 部分（开口可在 B0 内闭合，须写进 B0 计划）。

测量层 + 强制交付物：
- D-5 herding 跨臂方差 >"预注册下限"：**未通过（时序矛盾）**。OSF 预注册排在 B1 前（RM:22/246），即 pilot 之后——闸门运行时被引用的"预注册下限"尚不存在；§7:236 又把这些阈值定性为"pilot 验证可标定性后随 OSF 冻结"，与 RM:165 用作 go/no-go 直接冲突。修复：B0 出口先冻结《pilot 协议》（含全部判定阈值），B1 前 OSF 追认。
- D-6 实测 x 覆盖分箱最小比例（"预注册写明"）：同时序矛盾 → 部分；且回放下应改为"按池设计覆盖"在 B0 验收（A-2）。
- D-7 聚簇设计效应实测落盘回填 power 账：可测 ✓（属测量交付，无阈值）。
- D-8 token-overlap 区分度验证：判据为定性（"不足则换分布级指标"）→ 部分，可接受。
- D-9 充分性假设验证 + 回退触发判定：通过判据"随 OSF 预注册写明"（RM:98）→ 同时序矛盾 → 部分。
- D-10 manipulation check 达随机水平：阈值随预注册冻结 → 同时序矛盾；且探针统计设计（探针数、检验功效、二元/三元任务的随机水平定义）未规格 → 部分。

**开口合法性判定**：阈值留待冻结本身合法（RM:236 已登记，非漏洞）；但**凡被 go/no-go 引用的阈值必须在闸门运行前冻结**——当前形态下 pilot 闸门对 D-5/D-9/D-10 空转，这是漏洞不是合法开口。结算缺失率阈值（RM:187/236）未进 go/no-go，属合法开口。**遗漏**：回放臂专属判据（断网验证、快照时戳<开赛校验、结果泄露探针）未列入 go/no-go（→E5）；§7:236 开口注册表漏充分性判据（→B 表 RT-1 行）。

## E. 回放臂的新设计漏洞（此前各轮未审过）—— 8 个新洞

- **E1 快照时点规则缺席（fork path）**。x 的取值直接依赖快照时点（开赛前 T-1h 与 T-7d 的赔率不同，x 不同则 V(x) 不同）；RM:138 仅要求"早于开赛 + 时戳落盘"，无固定规则，且未列入预注册清单（RM:246）与冻结粒度清单（RM:157）。看完数据选时点是标准 fork path。
- **E2 快照可得性未验证、无备选源、无失败回退**。cds4polymarket 仅为"候选来源"（RM:96/138，只读纪律已正确声明）；其对世界杯以外赛事/事件的覆盖、时戳粒度、可用快照数量均未盘点。若不可用，回放臂失去 x 来源，v1.5 主干整体失去地基——§7 风险表无此行。落点虽在 B0(iv)，但无验收标准、无首周闸门（→F-1）。
- **E3 per-model 事件资格窗口未消歧，共享池被静默压缩**。RM:120 自载：gpt-oss-120b 截止 2024-06；Nemotron-3-Super-120B "预训练 2025-06 / **后训练 2026-02**"（Green Source：RM:120 及 `docs/investigations/open-model-cutoff-verification-2026-07-22.md`，经 `analysis/roadmap-v12-scan/CHANGELOG.md` 2026-07-22 Nemotron 核查行确认）。"截止日之后的事件"（RM:96/138）若按较早日期解读，[2025-06, 2026-02] 区间事件的结果可能经**后训练语料**泄露——而公开的 Nemotron-CC 只覆盖预训练（RM:120），后训练语料不可证伪。跨家族比较需共享任务池 → 池被限至 2026-02 后约 5 个月的事件，与"题目来源多样化"（RM:96）存在张力；RM:120"均早于 2026-06 开赛，回放无结果泄露"只对世界杯题成立，管不到"其他体育赛事/事件"。探索支臂（OLMo 3 2024-12 / Nano-30B 2025-06 / Llama-3.3 2023-12，同 CHANGELOG 核查行）同需入表。
- **E4 回放→前瞻可迁移性未登记（本次复查最重要新洞，与 RT-1 同型）**。V̂(x) 估计自历史事件（约 2025-06 至 2026-07），Stage 2 与未来期末考在前瞻事件上确认（RM:21/139/156）——"历史回放估出的曲线能搬到未来事件"是 v1.5 引入的新承重假设。但：§4.2 的充分性检验只管"V(x) 不依赖披露策略"（RM:98），不管跨期搬运；§7:233 的域偏移行是前瞻语境，缓释（块内分层配比）不对症跨期市场/机制漂移；B0.5 与 B1 均无"V̂_replay vs 早期前瞻子样本"对照设计；失败代价 = 前瞻蓄题数月（RM:166），与 RT-1"数月积累方法上作废"同型，却没有 RT-1 那样的登记 + 检验 + 预写回退。期末考的诚实报告（RM:158）是事后交代，不是事前保险。
- **E5 回放臂无 pilot，SE:A3 模式复发**。B0.5 判据全按前瞻管线写（RM:165）；断网执行、快照加载与时戳自动校验、资格窗口过滤（E3）、结果泄露探针等回放专属管道首次实跑即 B1 批量——正是 SE:A3"无试飞直接量产"在回放臂上的复发。
- **E6 manipulation check 对回放的标定不当**。RM:118 要求回放臂"赔率与结果认知应处随机水平"：对著名赛事，远期赔率与舆论在模型截止前已存在（世界杯 futures 早于 2024-06 开盘），模型合法记忆会导致"赔率认知"探针系统性不达标，而"该臂数据作废重跑"救不了——知识在权重里，重跑同样超标；若临时放宽则成 fork path。"结果认知"探针方向正确，但探针数与检验功效未规格。
- **E7 聚簇结构漏一层 + 设计效应可前置**。同届聚簇（RM:96）与同日聚簇（RM:164(iii)）已点名；**同队重复**未点名（世界杯 32 队各 3–7 场，同队比赛落入相近 x 分箱，箱内相关）——mixed-effects 应加队级随机效应；pilot 设计效应实测（RM:165）可兜底但偏晚。另：回放池固定使设计效应可在 B0 解析预估，不必等 pilot（与 A-2 同类未利用红利）。
- **E8 截止证据三级的写作落实有一处实际降级风险**。RM:118"按级引用、不得混用"要求在位 ✓；但第一级"语料公开可证伪"依赖 Nemotron-CC gated 审批（RM:120），审批 lead time 未进时间线（RM:166-168）；若 B1 时审批未过，Nemotron 的引用须降为第二级声明，写作素材应提前按降级口径准备。Hindcast 占位调查（B0 (vi)）同为"无占位判定标准、无占位后预案"（见 C 表）。

## F. B0 三件裁定的依赖顺序 —— 路线图阶段归属自洽，缺 B0 内部排序与失败回退

- **F-1 任务流与结算来源（含快照来源裁定）= 必须先定，且应排 B0 第 1 周**。它决定 V(x) 可定义性（RM:129 硬约束）、信息集旋钮、回放 x 来源；红队总评要求其"B0 启动前裁定"（RT:102），v1.5 以硬约束预限决策空间后留作 B0(iv)，可接受。但快照可得性子项（E2）实为**整个 v1.5 回放设计的 go/no-go**——路线图未给"B0 首周验证 + 不可用则回退"的条款。
- **F-2 自建 vs API = 与 F-1 并行、先于成本模型定稿**。§4.7 是 API 口径账（RM:172-176）；若自建（Super-120B 需 8×H100 或单 B200，RM:121），需 GPU 时子账，否则 B0.5 成本对账（D-4）无基准。API 路线须先实测付费档截断率（Tsinghua 免费端点 60% 截断教训，RM:121；Green Source：RM:121 及 Tsinghua 仓库核查记录）作为裁定输入。此裁定晚于成本模型定稿则 D-4 空转。
- **F-3 Stage 1 moderate n 定量 = 可后延，链路自洽**。依赖 RT-5(b) 逐臂/合并裁定（×6，RM:174）与实测/枚举 x 分布，收口于 B1 前 OSF（RM:246）——与 RM:138(c) 表述自洽。附带：回放下定量可部分前置到 B0（A-2），B0 计划可利用。
- **自洽性判定**：三件的阶段归属（F-1/F-2 在 B0，F-3 在 pilot 后）在 RM:164/138/121 间互相一致；缺的是 **B0 内部排序**（快照验证 → 部署裁定 → 成本模型点估计 → SOP 定稿）与 F-1/F-2 各自失败时的回退条款（§7 均无行）。
