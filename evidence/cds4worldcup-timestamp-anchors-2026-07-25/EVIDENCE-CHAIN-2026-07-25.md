## 一、证据链五层结构

| 层 | 内容 | 时间戳来源 | 寿命 |
|---|---|---|---|
| L1 git 历史 | 全量 commit（内容寻址 SHA-1），封存于 `cds4worldcup-all.bundle` | 自声明（不可单独作凭） | 永久（内容寻址） |
| L2 GitHub 服务端 | Actions 运行记录 148 条（最早 2026-06-11T06:28:03Z）+ Events API 61 条导出 | GitHub 服务器 | 400 天（已设，至 ~2027-08）；导出件已固化 |
| L3 第三方平台 | Gmail 通知邮件 8 封（6-11×3、6-13×2、6-18×2、6-20）+ Wayback 存档（2026-07-25 起） | Google / Internet Archive | 长期 |
| L4 字节固化 | bundle + worktree 822 文件 + 全部导出件与截图的 SHA-256 清单 | 本文件生成时间 | 配合锚定后不可改 |
| L5 外部锚定（待完成） | OpenTimestamps / RFC 3161 TSA、Zenodo DOI（embargo） | 比特币链 / TSA / CERN | 永久 |

**信任结构**：任何单层都不单独成立；主张由多层交叉支撑。伪造难度 = 同时伪造 L1 自洽哈希链 + L2 GitHub 数据库 + L3 Google/IA 服务器 + L5 区块链，且四者时间互相吻合。
