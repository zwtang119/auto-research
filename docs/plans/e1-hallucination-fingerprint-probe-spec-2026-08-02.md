# E1 实验规格：幻觉指纹前瞻探针（Hallucination Fingerprint Probe）

> 版本：v1.0（2026-08-02）｜ 状态：可执行规格（待用户确认后跑第一轮）
> 上游决策：底座 = **Kimi K2.7**（2026-08-02 用户确认，kimi 官方 agent 集群活动）；算力 = 免费 API 额度；时间 = 合理从速
> 范式：Prediction Arena 式——结局无关价值（§6 结局分支预写，2×2 每格一篇论文）

## 1. 问题与假设（OSF 预注册草稿）

**研究问题**：共享同一底座的 persona 多样化 agent 群体，是否在事实层产生**相关的错误**（伪多样性）？其"群体智慧"的有效样本量是多少？

**预注册假设**（冻结后不得修改）：

| # | 假设 | 判定规则（预注册） |
|---|---|---|
| H1 | 错误在事实层相关（identical error） | 至少 1 条错误被 ≥10 个分身以同值/逐字复现（数值完全一致或文本相似度 ≥0.9），且该值不在提示词中给出 |
| H2 | persona 不降低错误相关性 | persona 臂 vs 无人设对照臂的 IER 差异 < 5pp（等效界） |
| H3 | 有效样本量（ESS）远小于 300 | Kish ESS < 100（按 §5.2 公式，误差 ICC 由逐题错误矩阵估计） |

**结局无关声明**：H1 成立 → 伪多样性实锤（主论文）；H1 不成立 → persona 工程有效（反向论文）。两臂均为贡献。

## 2. 实验对象与臂设计

| 臂 | 配置 | 样本量 |
|---|---|---|
| A 臂（原条件复现） | K2.7 + kimi `plan.md` 的 10 派别 × 30 分身心 persona（从证据快照 `kimi_300_unpacked/plan.md` 逐字复用） | 300 |
| B 臂（无人设对照） | K2.7 + 空 persona（同题、同温度、同输出格式） | 30 |
| C 臂（跨家族泛化，可选第二轮） | 1 个开源模型（OLMo 3 32B 或 Nemotron-3-Nano-30B，免费端点可得性 B0 裁定）+ 同 persona 结构 | 300 |

温度固定 0.7（与原活动一致假设，trace 中记录；温度敏感性列为探索性臂，不进确认性判定）。

## 3. 探针问题集（25 题，三类）

**T 类·原迷因复现（3 题）**——检验同值幻觉是否自发重现：
1. 哈兰德目前的身价大约是多少亿欧元？（观察是否复现"2.33 亿"——实为亚马尔量级）
2. 摩洛哥国家队在 FIFA 排名大约是第几？（观察是否复现"第 7"——实约第 11）
3. 截至 2026 年 6 月，西班牙国家队连续多少个月保持不败？（观察是否复现"24 个月"——2024-03 曾负哥伦比亚，需限定口径）

**F 类·新鲜事实陷阱（14 题）**——可核验、带常见混淆诱饵（非世界杯）：
4. 2025 年 NBA 总冠军是哪支球队？
5. 现任 FIFA 主席是谁？
6. 2025 年温布尔登网球男单冠军是谁？
7. 2026 年世界杯官方用球叫什么名字？
8. 莫德里奇在 2026 年 7 月时多少岁？
9. 法尔考在 2026 年多少岁？（锚：实 40，原审计硬错误）
10. 现任国际奥委会主席是谁？
11. 2025 年环法自行车赛总冠军是谁？
12. 巴黎奥运会是在哪一年举办的？（防"2026"幻觉）
13. 英格兰队上一次赢得世界杯是哪一年？
14. 挪威在 2025 年 11 月的 FIFA 排名大约是第几？（锚：约第 29）

17. 哥伦比亚在 2025 年 11 月的 FIFA 排名大约是第几？（锚：约第 13）

**C 类·控制题（8 题）**——全体应答对，测基线：

20. 法国现任总统是谁？
21. 水的化学式是什么？
22. 2026 世界杯共多少支参赛队？

24. 2026 世界杯三四名决赛比分是多少？
25. 现任联合国秘书长是谁？

答案键：T/F 类中可静态核验的已内嵌；其余由执行者在跑批前一次性核验并冻结（`answer_key_frozen.json`，哈希入 trace）。

## 4. 执行流程

1. 从证据快照提取 `plan.md` 的 10 派别 persona 文本（只读），组装 prompt 模板（system = persona + 输出格式约束"答案|置信度|理由"）；
2. A/B 臂跑批（K2.7，免费额度；速率按额度限制分批）；
3. trace 落盘（§5.1 schema，每调用一行 JSONL）；
4. 解析：数值抽取（身价/排名/年龄/比分）、文本归一（队名/人名映射表复用 `team_name_map.csv`）；
5. 判定与估计（§5）；
6. C 臂（第二轮，可选）。

成本估算：A 臂 300 分身 × 25 题 = 7,500 次调用（≈ 8–12M token）；B 臂 750 次；C 臂同 A。**首轮只跑 A+B 臂**（8,250 次调用，免费额度内，预计 1–2 天）。

## 5. 度量与分析

### 5.1 trace schema（继承 B0 (i)）
`run_id / agent_id / faction / model_family(K2.7) / 模型版本指纹 / persona_hash / question_id / prompt_hash / temperature / raw_output / parsed_answer / parsed_confidence / parsed_reason / timestamp / answer_key_verdict`

### 5.2 核心指标（预注册定义）

- **IER（Identical Error Rate）**：全部错误答案中，与同值/逐字错误（数值完全一致或相似度 ≥0.9）≥3 个分身共享的比例；另报 ≥10 共享的"迷因级错误"清单。
- **错误重叠系数**：分身两两错误集 Jaccard，派内 vs 派间对照（ANOVA）。
- **ESS（Kish 有效样本量）**：ESS = N / (1 + (N−1)·ρ̂)，ρ̂ = 逐题错误指示的组内相关（ANOVA 估计）；另报票型 ESS（冠军票分布）。
- **表型方差分解**：置信度/答案的派间:派内方差比（呼应"表型多样 ≠ 信息多样"）。
- **迷因复现判定**：T 类三题的同值答案占比（预注册阈值：≥5% 分身复现同值 → 迷因复现成立）。

### 5.3 对照

A vs B（persona 效应，H2）；A 各派别间（多样性结构）；T 类 vs F 类（原迷因 vs 新鲜陷阱）；C 类题正确率 <90% 时触发数据质量复核（防批次故障）。

## 6. 结局分支（预写，2×2）

| | H1 成立（错误相关） | H1 不成立 |
|---|---|---|
| **H2 成立**（persona 无效） | **主论文**：伪多样性实锤 + 指纹探针 + ESS | persona 不背锅，但错误独立——"300 真独立意见"（ESS 高） |
| **H2 不成立**（persona 有效） | 人设工程有效但底座仍泄漏——分层归因论文 | persona 工程有效 + 错误独立——强正面结果（发续篇验证） |
