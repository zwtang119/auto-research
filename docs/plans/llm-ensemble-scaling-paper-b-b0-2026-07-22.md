## Approach

三阶段，先取证、再冻结、后试飞。**顺序即依赖**：快照与部署取证（首周）→ 交付物与阈值冻结（B0 出口）→ 双臂 pilot（B0.5）→ 放行 B1。

- **阶段 0（B0 首周）：双路取证闸门。** (a) 历史赔率快照来源盘点：覆盖域、时戳粒度、可用数量、固定快照时点规则、至少一个备选源——这是地基闸门；全部不可用 = **no-go**，回退选项预先写明（回退 A：Stage 1 回到 v1.4 纯前瞻时序；回退 B：改用资格窗口内其他带价数据源），需主干重议而非"如实披露"了事；候选源（含 cds4polymarket 历史数据资产）全程只读。(b) 部署取证：Super-120B 的 8×H100 / 单 B200 NVFP4 GPU 时成本子账；gpt-oss 自建资源；付费 API 的版本钉死/模型指纹/截断率/格式质量/限流小样实测（免费端点 60% 截断是质量先例，不等于付费端点已失败——以实测为准；若 API 实测失败转自建，硬件 lead time 进关键路径）。
- **阶段 1（B0 第 2–3 周）：六件交付物 + 横切冻结物。** 六件：trace schema、冻结验证 SOP、任务流调度规则、结算来源裁定记录、信息隔离 SOP、Hindcast 占位查新报告。横切冻结物（B0 出口必须随附）：《pilot 协议》（全部未定量阈值在此时冻结，含双臂样本分配矩阵）、一页成本点估计、事件资格窗口表（按**后训练截止**判定：gpt-oss-120b >2024-06；Super-120B >2026-02；共享池取窗口交集）、E4 风险/对照登记（与 RT-1 同等级：V̂_replay(x)→前瞻域可迁移性不自动成立，预写判据与回退，B1 早期前瞻子样本做 V̂_replay vs V̂_prospective 内对照 + 中期检查点）、回放池 x 覆盖枚举与设计效应预估。
- **阶段 2（B0.5，1–2 周）：双臂 pilot。** 回放臂：断网/快照/时戳/资格过滤/泄露探针全流程演习（≥100 次预测，含至少一次 n=30 全量配置演习）；前瞻臂：实时供题/落盘/结算时延验证；n=1 强基线臂实证能力地板。go/no-go 按已冻结判据逐项对账，通过后才定量 moderate n 并放行 B1。

**验收硬数值**（沿用路线图，不得降级）：trace 完整率 100%；解析成功率 ≥98%（批次 + 周聚合）；前瞻子流结算时延中位数 ≤72h（回放臂不适用）；成本实测相对 B0 点估计偏差 ≤50%。

**文献修正一处随本计划落实**：回放 manipulation check 分层——截止日前的合法 futures/舆论记忆豁免，赛果泄露单独检测，随机水平按二元/三元任务元数定义。（另：参照范式引证方向修正——single-agent baseline 超过 ~45% 后加 agent 可能负收益——属路线图文本问题，移交路线图 v1.6 处理，不占本计划篇幅。）

## Open Questions

- 付费 API 的具体端点/价格/版本固定能力——W2 实测前未知，计划中不预填数字。
- 历史快照候选源的真实覆盖——W1 闸门待验证事实，计划不把候选源写成已可用。
- 共享池交集（gpt-oss >2024-06 ∩ Super >2026-02 ∩ 任务流可得事件）的事件数是否足以支撑 moderate n——W1/W3 输出，若为否，触发资格窗口或任务流重议。
- Nemotron-CC gated 审批结果——W1 首周启动申请；未获批时写作证据等级降级处理，不假装已独立核验语料。
