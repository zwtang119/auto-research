## 1. 规格不足的接缝 Top3（done-when 无法验收）

1. **E4 登记与 x 覆盖枚举无工作项承接**（plan:25 vs plan:36–43）。阶段 1 横切冻结物列出"E4 风险/对照登记（预写判据与回退）"与"回放池 x 覆盖枚举 + 设计效应预估"，但 W 表没有任何 done-when 承接；W8 仅提"B1 放行清单（含 E4 内对照设计）"，登记物本身的完成判据（对标 RT-1 格式：风险行 + 检验 + 预写回退，RC:77,96）无处验收。E4 是复查认定的最重要新承重假设，其登记物恰恰漏出验收网。
2. **W1 no-go 回退无规格**（plan:36, 24）。"全部不可用时……改主干"只有三个字；RC:85（F-1）要求"不可用则触发 Stage 1 回放整体回退"且对标 RT-1 预写回退格式。回退形态（改回前瞻 Stage 1？换任务流路径？）未预写——首周闸门一旦触发，本计划 W3–W8 失效且无接续方案。
3. **W7 回放臂专属判据归属不明 + n=1 地板无合格线**（plan:41–42）。W6 冻结清单（herding 方差下限、x 覆盖比例、探针数/功效、充分性判据、成本点估计、分配矩阵）未显式含回放臂的断网验证、快照时戳<开赛自动校验、资格窗口过滤的通过判据（RC:97 必进清单 4）；W7"判据逐项达标"可能漏核回放侧。n=1 基线臂"实证能力地板"（plan:26）无合格线、无不达回退（换底座？降级主张？）——而能力地板是主力选型理由 (i) 的承重前提（RM:120）。

- **无环**：W1/W2/W4/W5 → W3 → W6 → W7 → W8 是合法 DAG；D-5/D-9/D-10 时序修复（阈值 W6 冻结 → W7 对账 → W8 OSF 追认）与 RC:88（F 顺序结论）一致 ✓。
- **W7 依赖缺 W1、W3**（plan:42）：回放臂演习"快照/时戳/资格过滤"直接消费 W1 快照源裁定与 W3 资格窗口表；现表允许 W7 在 W1/W3 未完成时启动。
- **W4 对 W1 有隐性依赖**（plan:39）：信息隔离 SOP 的时戳校验与 manipulation check 分层依赖 W1 产出的固定快照时点规则（E1，RC:74）；W4 标"无依赖"会导致 SOP 先于时点规则定稿、事后返工。

- **"双臂样本分配矩阵"降格**（plan:25, 41）：pilot 仅 ≥100 次预测，三臂（回放/前瞻/n=1）分配一句原则（回放臂为主、前瞻臂最小量验证结算时延）即可，矩阵规格超前。

## 4. 会改变执行顺序的未决问题

- **付费 API 实测结果**（plan:47）：截断率/版本固定能力若不达标 → 转自建，8×H100/B200 的采购或排队 lead time 进关键路径，W2 量级与 W6 成本结构同时改变；W2 应尽量压进首周，而非宽松地"与 W1 并行"。
- **快照闸门结果**（plan:48）：W1 no-go 即"改主干"，W3–W8 全体重议——已是显式闸门，但它意味着"首周只跑 W1+W2 取证"是唯一安全排法，W3–W5 不宜提前动工（现计划未声明此约束）。
- **Nemotron-CC 审批 + 共享池交集大小**（plan:49, 25）：审批否决动摇 Super-120B 主力地位（选型理由 ii，RM:120）；更直接的未知量是交集窗口（>2026-02）内可得事件数与 x 分布形态——若不足以满足分箱下限，W6 阈值与 W7 规模须重排。此未知量未列入 Open Questions，应补。
