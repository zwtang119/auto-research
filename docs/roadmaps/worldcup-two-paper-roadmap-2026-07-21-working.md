## 4. Paper B（下半篇）：LLM 群体路径的前瞻 scaling 验证

### 4.1 研究问题

**不问**"kimi 当时为什么对"（不可证伪，已拒收）；**改问**：

> 在 LLM 群体预测中，何种结构（群体规模 × 人设多样性 × 聚合规则 × 信息集）导致 herding（趋同跟风），何种结构保住独立判断？

kimi 的 300 分身配置仅作为**假设来源（hypothesis-generating anecdote）**出现，全文措辞纪律：永远"一个有悬念的配置提示了这个方向"，永远不说"kimi 证明了 300 分身有效"。

**herding 的操作化定义**（预注册前必须锁定，缺它则标题构念不可测量）：判定主结构 = 内部一致性 × 信息集臂因果对比，全部可从 trace 自动计算——
1. **群体内部一致性**：同任务内分身输出的方差分解 / token-overlap（参照范式指标族）。测量层隐患（RT-7）：token-overlap 对短概率输出区分度低（两个独立得出 0.65 的分身产生几乎相同的 token 序列），B0.5 pilot 须验证其区分度，不足则换分布级指标（解析后概率的方差分解）；
2. **群体-市场一致性**（描述性统计，不单独具 herding 效度）：群体输出相对市场共识的偏差方向统计 + 信息增益 ΔI（接 v2 H4 框架）。群体与市场一致既可能是 herding（复述共识）也可能是"独立得出同一正确答案"，只有 §4.2 的信息集消融臂能把两者分开——故本指标仅作描述，herding 判定显式以"指标 1 × 信息集臂对比"为主结构（RT-7 修复："双层指标"名不副实问题）；
3. 判定阈值随 OSF 预注册冻结（已排期开口，B0.5 pilot 须验证阈值可标定性，见 §4.6）。
4. **机制注记**（v1.3）：AMW 与 Dunning 独立互证——人对 AI 预测的 under-response 几乎完全源于**对自身信号精度的过度自信**（own-signal overconfidence），而非对 AI 的不信任。对 Paper B 的含义：herding 的对立面（独立判断）可能同样由"分身对自身 persona 信号的过度加权"维持，herding 由此从"输出相似度"问题深化为**信念更新权重**问题；该机制列为 Stage 2 的候选机制假设（跨域借用 human reliance → agent herding，引用时须声明，见 §10 AMW/Dunning 条目）。

### 4.2 实验设计：AMW 充分统计量两段式主干 + 旋钮分级（v1.3 重构；v1.4 按 RT-1/RT-2/RT-4 补强；v1.5 Stage 1 改回放 + 底座定稿）

**两段式主干**（AMW 框架跨域借用，human-AI 协作 → LLM 群体，引用时须声明；v1.1 的"方案 A 扩量 / 方案 B 砍假设"二选一被两段式吸收而取消）：

- **Stage 1（描述性，moderate n；v1.5 改 cutoff-hindcast 回放）**：估计充分统计量 **V(x) = 群体正确率对市场隐含概率 x 的响应曲线**（从 trace + 结算数据非参数估计；参照 AMW 第一阶段"先估 V"模式，V 的凸性/形状用于推导最优披露与聚合策略）。v1.5 起 V(x) 估计不再等待未来事件结算，改用**截止日回放**：用训练截止日早于事件的开源模型，对其截止日之后的已结算事件回放预测——赛事结果早已揭晓，无需等待，Stage 1 时间从数月压到数周。题目来源多样化：2026 世界杯（同届聚簇，只占一部分）+ 截止日之后的其他体育赛事/事件（避免单一赛事 n=1 放大版）；x 取**事件发生前的历史市场赔率快照**（cds4polymarket 项目的历史数据资产是候选来源，引用时遵守只读纪律）。回放臂的防泄露纪律与 Stage 1/Stage 2 证据等级分工见 §4.3/§4.5。
- **Stage 2（确认性，集中 power）**：在 V(x) 基础上推导并验证**最优聚合/披露策略**（参照 AMW 第二阶段"按冻结策略实测验证"，其预测与实测差 <1.6pp）。确认性假设集中到 Stage 2 的 **1–2 个预注册主效应 + 显式 MDE 声明**（如"本实验可识别 α*≥0.05 的效应"），其余全部为探索性分析、不做确认性断言——v1.1 方案 B 的精神由"备选"扶正为默认设计。
- **充分性假设验证（RT-1 修复，两段式主干的承重假设）**：假设"V(x) 不依赖披露策略"是 AMW Assumption 2.1/2.2 的跨域对应物，**不自动成立**——AMW 的 x 是展示给决策者的 AI 评分（其校准受控），Paper B 的 x 是任务属性（事件的市场隐含概率，agent 未必可见），充分性定理（二元分类、校准评分、单决策者）不自动覆盖本设定，因此检验它不是可选项而是必修课。落点：列为 **B0.5 pilot 的强制交付物**——在小规模上检验 V̂(x) 在不同披露/聚合策略下的稳定性（检验方法借用 AMW Assumption 2.1/2.2 的检验，通过判据与样本量配额随 OSF 预注册写明）。**失败回退（预写）**：若充分性假设被拒，放弃 AMW 两段式主干，回退到 2 确认性旋钮（规模 × 信息集）的小型直接 factorial。V(x) 低 x 区间（冷门事件）样本稀疏须如实披露（回退规则见 §4.3）。
- v1.1 的"两阶段 adaptive design 写入预注册"要求由两段式主干吸收：Stage 1 = 估计、Stage 2 = 确认，两段规则均写入 OSF 预注册，不再另设筛选规则层。

**旋钮分级**（v1.3：确认性旋钮砍至 2 个，36 格全确认性 factorial 取消——SE review 判定人设、聚合为二阶问题，拿 4 倍样本量换非核心结论属过度设计）：

| 级别 | 旋钮 | 水平 | 检验什么 |
|---|---|---|---|
| 确认性 | 群体规模 | 3 / 10 / 30（对数间隔） | 规模收益曲线形态；是否存在过规模负收益（参照范式：single-agent 超 ~45% 后加 agent 呈负收益） |
| 确认性 | **信息集**（M5 落实，v1.1 第四旋钮地位提升） | 含市场快照 / 不含市场快照 | herding 的因果识别：操纵 agent 能否看到市场信息，是区分"跟风复述"与"独立同答"的唯一干净手段 |
| 探索性 | 人设多样性 | 同构 / 派别差异化 | persona 差异化是否产生实质性信息异质（接 v2 H4-ii 开放问题）；Stage 2 候选机制（信念更新权重，§4.1 机制注记）的探索载体 |
| 探索性 | 聚合规则 | 多数投票 / 加权 / 辩论收敛 / **选择性路由（selective routing）** | AMW 发现最优策略为"选择性自动化 + 完全披露"、协作辅助相对其增量**可忽略**——增设选择性路由臂（按置信度把任务路由给最优子群体，其余直接采纳），检验该发现在预测任务上是否成立（跨域借用须声明）；AMW"完全披露不劣于部分披露"提示信息集臂可加"完整快照 vs 加噪/延迟快照"子水平 |

- 规模水平说明（v1.3）：**300 分身降为可选探索探针**——300 是 kimi 轶事值而非机制需要，曲线形态用对数间隔小水平即可识别拐点与负收益区，300 臂成本约为 3 臂的 100 倍却只贡献曲线末端一个点（成本约束见 §4.7）；写作中明示"本实验检验的是曲线形态而非复刻 300 这一点"（与 §6 第 6 条认识论绝缘裁定一致，呼应 kimi 叙事只剩修辞价值）。

### 4.3 样本量与统计（v1.3 两段式集中 power，方案 A/B fork 取消；v1.4 按 RT-5 补 Stage 1 规格；v1.5 Stage 1 改截止日回放）

**锚点溯源**：Foresight Arena [arXiv:2605.00420] 原文（2026-07-21 直接复核摘要页）："detecting a true edge of α* = 0.02 at 80% power requires approximately 350 resolved binary predictions"。该数字属实，但适用边界有三：二元任务、两 agent 单一比较、"50 rounds × 7 markets" 存在时间聚簇（独立有效样本 < 350）。v1.1 曾把它摊到 18 格 factorial（每格 ~19），SE review 进一步指出第四旋钮加入后实为 36 格、缺口约 20 倍且未对账——v1.3 以两段式消解：取消全确认性 factorial，确认性 power 集中于 Stage 2（§4.2），36 格对账问题不再存在。

**两段式 power 账**（启动 B1 前写入 OSF 预注册）：

- **Stage 1（V(x) 估计，描述性；v1.5 改 cutoff-hindcast 回放）**：目标是曲线形态而非单点显著；n 按曲线分箱精度定（moderate n），预注册中写明分箱规则与每箱样本下限。**回放设计（v1.5）**：题目 = 模型截止日之后的已结算事件（结果早已揭晓，无需等待结算周期，Stage 1 时间从数月压到数周）；来源 = 2026 世界杯（同届聚簇，只占一部分）+ 截止日之后的其他体育赛事/事件（避免单一赛事 n=1 放大版，跨赛事分散同时缓解时间聚簇对有效样本量的侵蚀）；x 横轴 = **事件发生前的历史市场赔率快照**（候选来源：cds4polymarket 项目的历史数据资产，引用时遵守只读纪律；快照时间须早于事件开赛，快照时间戳随 trace 落盘）。**证据等级分工（v1.5）**：Stage 1 从宽——模型截止日可验证（三级分级的前两级：语料公开可证伪 / 官方模型卡声明）即可入场，回放结论的效力不依赖"无人能知答案"，而依赖"该模型不可能知道答案"；Stage 2 与期末考从硬——必须为前瞻事件（未来事件，物理上不可能知道答案），见 §4.5。规格补强（RT-5 修复）：(a) x 分布外生不可控（真实市场二元任务价格集中两端、体育三元任务隐含概率集中中段，总有覆盖不到的区间）——预注册写明**各分箱样本下限与未达下限的回退**（收窄主张区间 / 定向补充任务源，而非仅"如实披露"）；(b) **逐臂估计 vs 跨臂合并**须在预注册中裁定：逐臂估计则样本预算乘 6（3 规模 × 2 信息集），合并则须先检验"曲线可跨臂合并"假设并写明可检验性判据；(c) "moderate n" 在 B0.5 pilot 后以实测 x 分布定量（此前为规格缺席，登记在案）。低 x 区间（冷门事件）样本稀疏如实披露。
- **Stage 2（策略验证，确认性）**：1–2 个预注册主效应，样本量按**显式 MDE 声明**反推（锚点：α*=0.02、80% power ≈ 350 已结算二元预测/比较；任务流时间聚簇按设计效应折算有效样本量，mixed-effects 之外 power 估算须用聚簇调整后口径）；评估集自身须满足 MDE 要求，否则期末考在设计上注定不显著。
- 任务口径：若用体育 W/D/L 三元任务（RPS），须重做 power analysis 或改用二元市场任务对齐锚点。**v1.6 落实（M-4 修复，防锚点口径静默漂移）**：B0 任务流裁定后即以观测 x 分布（市场隐含 W/D/L 三类概率）× 三类结算重做 power 模拟，产出 RPS 三元锚点 n_RPS_min 报告（列为 B0 成本模型附件）；二元锚点 350 仅作 cross-check 参照；预注册冻结二元（Brier）/ 三元（RPS）双锚点表，事后换口径视为违反预注册、须 OSF 修订留痕。
- 分析：混合效应模型 + bootstrap + 交叉验证 + 全套模型设定诊断（残差 / VIF / 正则化对照，对齐 Scaling Agent Systems 范式）；负结果必报；除均值外报告跨条件方差（"平均最优 ≠ 鲁棒最优"，换模型家族/任务流后不稳健的配置如实标注）。
- 逐场层做推断，赛事级单点仅描述（不重复 n=1 的错误）。

### 4.7 成本估算（量级与降级规则；v1.3 新增，v1.4 拆分子账）

- **调用量公式**：API 调用次数 = 已结算预测数 × 分身数 × 模型家族数；辩论收敛臂多轮交互再乘 3–5 倍。
- **量级区间（RT-9 修复：分子账报价，探索臂不再隐身）**：B0 一页成本模型分列两个子账——
  - **确认性主干子账**：Stage 1（moderate n × 规模臂 3/10/30 × ≥2 模型家族）约 10⁴–10⁵ 次调用；Stage 2（按 MDE 定量 × 确认性 2 旋钮）同量级或更低；主干合计为**量级口径而非严格上界**——两阶段均顶格时合计可达约 2×10⁵ 次调用（v1.6 修正表述，R3 审计发现），10²–10³ 美元同为量级口径（注：若 RT-5(b) 裁定为逐臂估计，Stage 1 样本预算乘 6，主干自身顶破上界，须在预注册中连同该裁定一并重报本子账）；
  - **探索臂子账**：300 探针臂（300 分身 × 2 家族 = 600 次调用/任务）与辩论收敛臂（多轮交互再乘 3–5 倍）单独列账；**300 探针臂设成本硬上限：任务数 ≤50 个（约 ≤3×10⁴ 次调用），超限即不启动或直接触发降级**；
  - **头条区间（含探索臂口径）**：全篇合计约 10⁴–10⁶ 次调用、10²–10⁴ 美元区间。B0.5 成本对账按两个子账分别核。

### 4.8 运行期监控（B1 常驻；v1.3 新增，v1.4 补分析侧与恢复规则）

每次运行落盘四字段：调用数 / 解析成功率 / 模型版本指纹 / 结算状态；周级自动对账。三类静默失败的校验节点与处置规则（与项目既有 fail-loud 纪律同构）：

| 静默失败 | 机理 | 校验与处置 |
|---|---|---|
| 解析漂移 | 分身输出格式漂移 → 概率解析失败被静默丢弃，各臂存活率不等即引入选择偏差 | 解析成功率 <98% 即 fail-loud 停流排查，修复前的数据分段标记。**判定窗口双层**（RT-10 修复）：按运行批次（单批越线即停）+ 周聚合（防漂移潜伏） |
| 结算延迟 | 结算延迟 / 市场作废 → 样本悄悄缩水且非随机缺失 | 周级结算状态对账，缺失率超阈值（预注册写明，已排期开口登记在案）即停流并记录缺失机制 |
| API 版本变更 | 服务端模型版本变更使"版本固定"承诺悄悄失效（prompt hash 管不住 system 侧） | 模型版本指纹逐次落盘，指纹变更即 fail-loud 停流，变更前后数据在分析中分段标记 |

**分析侧与恢复规则（RT-10 修复，预注册补写）**：

- **标记段的分析规则**：不单列剔除——若解析漂移与臂相关（30 臂长输出更易格式漂移），按臂不等剔除恰好重新引入监控本想防的选择偏差；统一做"含/不含标记段"的**双口径敏感性分析**，两口径结论不一致时如实披露。
